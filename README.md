## Quick Start
1. **Clone & Install**
   ```bash
   npm install
   ```
2. **Setup Env**
   ```bash
   cp .env.example .env.local
   # Fill in Supabase & OpenAI keys
   ```
3. **Run Dev**
   ```bash
   npm run dev
   ```
